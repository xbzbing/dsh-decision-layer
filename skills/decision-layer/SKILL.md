# 手动裁决

当用户要求手动裁决时，用 `decision_evaluate` 提交最少的任务上下文和一组结构化问题。此调用只展示判断结果，不控制 agent 工具、审批或回合流程，也不计入自动裁决总数。

- `state` 是与判断相关的文字、对象或数组，不放密钥或不必要的完整对话。
- `questions` 以稳定 ID 作为键；每个问题必须有 `type` 与完整的 `instructions`。
- `choice` 的 `criteria` 是至少两个候选 ID 到描述的映射；`score` 的 `criteria` 是从低到高的 2–10 个等级；`noul` 用于明确的二元条件。
- 解释结果时如实呈现概率、分数及模型名。裁决建议不替代用户选择，也不授予权限。服务不可用时说明事实，不杜撰结果。

需要验证配置时，可调用 `decision_check_connection`；它会向已配置的后端发送一条测试请求，但不会增加自动裁决计数。不要请用户在对话里粘贴 Key。
