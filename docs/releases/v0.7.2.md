## 主要变更

- **决策日志带上「场景（任务节选）」**：收窄、门控与自检行都能看到本轮任务（最多 512 字，剥离记忆 / 系统提醒注入块并遮蔽常见凭据）；收窄与自检行另带回合号，可在面板中展开原文，便于回看拦截与打分是否合理。节选只写入本地日志 / 快照并展示在本地面板与分析页，不随裁决请求外发。
- **凭据掩码更完整**：补上全角冒号、中文键名（密码 / 口令 / 令牌等）、URL 里的用户名密码、折行 Bearer、多词口令，以及 `sk-`、`ghp_`、`AKIA`、`glpat-`、JWT 等无标签 token；落盘前再掩码一次作为第二道边界。
- **失败即放行**：门控读取任务节选出错时只省略该字段，不会把一次工具调用变成错误。
- **内部**：host 半迁移到 TypeScript 并统一 `npm run build`；`npm run check` 现在包含 `npm pack` 断言（声明文件、`meta.detail`、`files` 清单），发布链路与文档同步更新。

## English

- **Decision logs now carry the task excerpt**: narrowing, gate and self-check rows show the turn's task (up to 512 characters, with injected memory/system-reminder blocks stripped and common credentials masked); narrowing and self-check rows also carry the turn number, and the panel can expand the text, so a block or a score can be reviewed in context. Excerpts are local-only: they go to the local logs/snapshots and panel/analysis view, never to an adjudication request.
- **More complete credential masking**: full-width colons, Chinese key names (密码/口令/令牌 …), URL userinfo, wrapped `Bearer` headers, multi-word passphrases, and unlabeled tokens such as `sk-`, `ghp_`, `AKIA`, `glpat-` and JWTs are now masked; storage applies the same rules again as a second boundary.
- **Fail open**: if reading the task excerpt fails, the gate only omits that field — it never turns a tool call into an error.
- **Internal**: the host half moved to TypeScript with a single `npm run build`; `npm run check` now includes the `npm pack` assertions (declarations, `meta.detail`, `files` list), and the release pipeline and docs were updated accordingly.
