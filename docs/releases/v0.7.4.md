## 主要变更

- **低评分记录能直接定位**：自检行恢复行内任务节选，低分行带「低评分」徽标与强调色；决策分析页新增「只看低评分（N）」，服务端先过滤再分页，长会话里也能直接找到被打分的回合。低置信低分仍按噪声显示，不会误报为质量下滑。
- **短追问的自检上下文更完整**：背景里的 assistant 消息改为保留结尾，短追问（「继续」「补上」）能看到上一轮末尾的交接问句；超长回复按开头 16K 字符 + 结尾 8K 字符采样，避免只看开头漏掉结论；评分输入补充短追问说明。外发范围仍是同一份有界快照。
- **内部**：ADR-0016 补充前文截取方向；新增低分筛选、行内任务节选与上下文截取的回归测试。

## English

- **Low scores are now easy to locate**: self-check rows show the task excerpt inline again, low rows carry a "low score" badge and accent, and the decision-analysis tab has a "Low scores only" filter that runs before pagination. Low-confidence low scores remain marked as noise, so they do not read as a quality dip.
- **Better self-check context for short follow-ups**: the assistant background message now keeps its ending, so a follow-up such as "continue" or "add it" can see the hand-off question from the previous reply; over-long replies keep a 16K-character head and an 8K-character tail so the conclusion is not lost; the score input explains how to use a short follow-up. The outbound scope remains the same bounded snapshot.
- **Internal**: ADR-0016 records the background excerpt direction; regression tests cover the low-score filter, the inline task excerpt and the context excerpts.
