## 主要变更

- **收窄默认更激进**：摘除阈值 0.3 → 0.7，默认保留前缀只留 `mcp__openviking`，`team_task_` 回到常规判定；只有模型较有把握判为相关的工具才保留。已保存过高级配置的用户仍沿用自己保存的值，要采用新默认需在配置页改回 0.7 与 `mcp__openviking`（或删除这两个字段）
- **收窄修复**：可选工具被全部摘除时不再作废整轮判定；关闭收窄后上一回合的 agent 级工具限制会释放；被 low-keep 否决的收窄不再显示「已生效」，收窄次数与收窄率只统计真正生效的判定
- **决策分析页会话开关**：页头可直接切换本会话的自动介入，与 dock 面板写同一份会话状态；读取失败时显示「不可用」并可点击重试，可访问名称与可见文字一致
- **插件详情页**：接入中英文 `meta.detail`，详情页按语言展示简介，不再回落到 README
- **内部**：发布改为「版本号变更推入 main」自动执行，npm 用 Trusted Publishing（OIDC）发布并带 provenance，不再依赖长期 token；README 隐私段与 AGENTS.md 同步更新

## English

- **More aggressive narrowing by default**: the drop threshold moves from 0.3 to 0.7 and the default keep-prefix is only `mcp__openviking`, so `team_task_` is judged like any other optional tool and only tools the model rates as fairly relevant survive. Users who saved advanced settings keep their saved values; to adopt the new defaults, set the threshold back to 0.7 and the prefix to `mcp__openviking` (or remove both fields)
- **Narrowing fixes**: dropping every optional tool no longer voids the whole pass; turning narrowing off releases the previous turn's agent-scoped restriction; a pass vetoed by low-keep no longer claims "enforced", and the narrow count / rate only include passes that actually took effect
- **Session switch in Decision analysis**: the header can toggle automatic interventions for this session, writing the same session state as the dock panel; a failed read shows "unavailable" with a click-to-retry, and the accessible name matches the visible label
- **Plugin details page**: bilingual `meta.detail` is wired in, so the details page shows the localized intro instead of falling back to the README
- **Internal**: releases now run automatically when a version bump lands on main, and npm publishes through Trusted Publishing (OIDC) with provenance instead of a long-lived token; the README privacy section and AGENTS.md are updated accordingly
