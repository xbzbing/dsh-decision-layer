## 主要变更

- **回合中途的只读过程检查（默认关闭）**：在插件详情页高级设置显式开启后，同一回合没有新用户输入时也能按进展心跳、持续未解决失败、验证后又修改产物三类检查点做后台判断。只使用当前要求与有界脱敏工具证据，结果分为「未见需复核问题 / 值得复核 / 证据不足」，低置信保持不确定；不追加提示、不限制工具，也不改变原有自检、完成核对与收窄。每会话单在途、合并最新候选、滚动 24 步最多 4 次、全局并发 4、短截止时间；新要求、压缩、取消或会话关闭只留下中性成本记录。发起前请确认已在详情页配置好裁决端点。
- **决策测量**：四个既有决策点补充请求关联 id、耗时、后端请求次数与提供方报告的 usage；分析页新增测量卡片与覆盖率，缺失保持「未知」而不是 0，重试时成功响应的 usage 也不代表所有尝试的总计费。手动 `decision_evaluate` 不返回这些内部测量字段。
- **日志与分析页**：决策日志新增只读过程检查行，展示触发原因、回合/步骤、证据截至序号与候选数量；沿用同一份人工标注，过程结果独立计数，不进入最终回复质量趋势。
- **内部**：ADR-0017 记录边界；新增执行观察器、检查调度器、测量与日志白名单，并补齐真实宿主事件、取消/过期、预算与脱敏回归。

## English

- **Read-only mid-turn process checks (off by default)**: after enabling in advanced settings, progress heartbeats, repeated unresolved failures and edits after a successful verification can schedule a background judgement inside the same turn without another user prompt. It sends only the current request and bounded, redacted tool evidence; results are "no concern observed / signal for review / insufficient evidence", and low-confidence concern stays uncertain. No prompts are added and no tools are restricted; the existing self-check, completion review and narrowing are unchanged. One in-flight check per session, latest candidate only, four checks per rolling 24 steps, four concurrent checks globally and a short deadline; new input, compaction, cancellation or a closed session leaves only a neutral cost record. Configure the decision endpoint first.
- **Decision measurements**: the four existing decision points now record a request correlation id, latency, physical backend requests and provider-reported usage; the analysis tab adds a measurement card and coverage. Missing data stays "unknown" rather than zero, and usage returned after a retry is not treated as the total for every attempt. Manual `decision_evaluate` does not return these internal fields.
- **Log and analysis view**: decision-log rows for read-only process checks show the trigger, turn/step, evidence sequence boundary and candidate count; they reuse the same annotation flow and are counted separately, never entering the final-reply quality trend.
- **Internal**: ADR-0017 records the boundaries; new execution observer, checkpoint scheduler, measurement and log whitelist, with regressions for real host events, cancellation/staleness, budgets and redaction.
