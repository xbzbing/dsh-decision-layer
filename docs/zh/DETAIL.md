# 决策层

为 DeepSeek Harness 的 agent 循环提供一组边界清晰的结构化裁决：危险调用要不要拦、当前工具够不够用、这轮产出有没有遗漏，都由可插拔的裁决模型给出建议，具体行为始终由宿主决定。

## 功能

- **危险调用门控**：破坏性工具调用执行前，用脱敏摘要请后端裁决；只有高置信「拒绝」才拦截，后端失败、低置信或响应不合法时一律按宿主原路径执行。
- **产出自检与质量趋势**：回合结束给最终回复打分，低分且模型有把握时可自动补一轮；连续多次高置信低分会在触发按钮上给出告警。
- **任务完成核对**：用户明确列出多个交付条件时，逐项判定「已满足 / 未满足 / 证据不足」，条件只取本回合最近一次要求，以本回合工具证据为准（上一回合的成功不算数），回复自述不算证据。
- **工具收窄**：回合开始时、以及同一回合内出现新的用户要求时，判断各可选工具与任务的相关性并摘掉用不上的；每次重新判断前先释放旧限制，时间提示与后台通知不触发重判。只在宿主已允许的工具集内取交集，绝不扩权。
- **防循环**：同一调用连续重复超过阈值即拒绝，确定性本地逻辑，不依赖后端。
- **决策面板与分析页**：展示自动裁决指标与决策日志，并可逐条标注「判对 / 判错 / 说不准」；分析页顶部可直接开关本会话的自动介入。

裁决后端、各决策点开关与介入阈值均可配置；默认值仍是未标定的启发式。
